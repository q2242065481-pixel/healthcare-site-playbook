# 大健康官网搭建技能包（healthcare-site-playbook）

把一个企业官网（医疗/养老/大健康行业）**从 0 到交付上线**的完整方法论。实战来源：广州卓越大健康集团官网项目（泰康之家对标 + ScrewFast 底座 + 阿里云部署）。

## 怎么用（新设备 30 秒上手）

把下面这段话**原样复制**发给 WorkBuddy / DeepSeek 类 AI 助手：

```
请克隆并阅读这个仓库：https://github.com/q2242065481-pixel/healthcare-site-playbook
先读 SKILL.md，然后严格按里面的六阶段流程执行：从「阶段0 需求澄清」开始，
一步一步来，每个阶段产出交付物并等我确认后，再进入下一阶段。
```

AI 会按这个节奏带你走：

```
阶段0 需求澄清 → 阶段1 对标拆解 → 阶段2 开源选型 → 阶段3 搭建 → 阶段4 三端验收 → 阶段5 部署上线
（问清需求）    （拆同行官网）   （GitHub选模板）  （动手写码）  （截图验收）     （服务器+备案）
```

**每一步都有确认门**——AI 必须产出交付物并征得你同意，才能进入下一步。不允许跳过需求直接搭。

## 这套方法论的前提假设

- 建站目标：企业**展示型**官网（无交易、无复杂后台）
- 技术路线：Astro 静态站 + 开源模板改造（不选 SaaS 建站、不上 CMS）
- 部署路线：国内云服务器 + Nginx 静态托管 + ICP 备案
- 操作者：零基础新手也能跟着走（所有命令可复制）
