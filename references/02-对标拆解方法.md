# 02 · 对标拆解方法（阶段 1 必读）

> 目标：把同行优秀官网拆成"照着抄的施工图纸"。实例：泰康之家（taikangzhijia.com）+ 越秀银幸（yinxinglife.com）。

## 一、选对标的原则

- **同行业同地域同模式**优先（如广州医养结合 → 越秀银幸几乎镜像）
- 结构对标和皮肤对标可以分开：A 站学**结构**（板块流、转化路径），B 站学**视觉气质**（配色、文案调性）
- 建议 2~3 个：1 个主抄 + 1~2 个参考

## 二、拆解动作（技术上怎么做）

1. **抓结构**：用 WebFetch 提取首页 + 关键子页（关于/业务/新闻/联系）的导航和板块结构
2. **看真容**：WebFetch 看不到视觉效果，必须用无头浏览器真实渲染：
   - 全页截图 + 逐屏滚动截图（每屏 700~900px），至少覆盖首页全部板块
   - 工具：agent-browser 或 playwright-core 直驱 Chromium
3. **逐板块记录**：板块顺序、标题文案句式、内容形式（轮播/大数字/卡片/tab）、交互效果、CTA 文案和位置
4. **提视觉规范**：主色（取色值）、眉题+标题组合样式、图片风格（真人实拍 or 插画）、留白程度
5. **抄转化设计**：电话 CTA 位置、预约表单字段、悬浮工具栏、页脚结构（备案/二维码/站点地图）

## 三、拆解笔记模板

```markdown
# XX官网拆解笔记
## 整体风格
- 主色 / 字体感觉 / 图片风格 / 气质关键词（如"温暖可信"）
## 首页板块流（从上到下）
1. Hero轮播：N张，文案句式"____，____"，按钮指向__
2. 大数字信任墙：4个数字（年限/机构数/床位数/满意度）
3. ...（每个板块：形式+文案句式+交互+CTA）
## 全局元素
- 导航（吸顶？下拉？CTA按钮？）
- 悬浮工具栏（电话/客服/回顶部）
- 页脚（站点地图/电话/二维码/ICP备案/公安备案）
## 效果清单与实现难度
| 效果 | 实现方式 | 难度 |
## 双对标分工（如有）
- 结构学__，皮肤学__
```

## 四、泰康之家实例要点（养老行业可直接参考的结论）

- 主色泰康橙 #FF8200 系；每板块固定「橙色小字眉题 + 加粗黑标题」
- 首页 9 板块：Hero轮播 → 大数字墙 → 五位一体 → 整版橙色理念块 → 对勾卖点清单 → 证言轮播（圆头像+手写感谢信）→ 双Tab资讯 → 三列图片卡（跳公众号）→ 预约表单（称呼+电话+验证码+院区下拉）
- 情感化文案："开门尽是笑脸，醒来必是节日"
- 页脚整版橙色：双热线 + 公众号/视频号二维码 + ICP + 公安备案
- 悬浮工具栏：电话 / 在线客服 / 回首页

## 五、合规注意

拆解是学习**结构和设计语言**，不是抄文案抄图片。落地时文案必须重写、图片必须用自有素材，尤其不能搬运对标站的人物照片和证言。
