# 06 · 部署上线手册（阶段 5 必读）

> 默认路线：阿里云轻量应用服务器 + Nginx。分两阶段：A = IP 预览（当天），B = 域名+备案+HTTPS（2~4 周）。

## 阶段 A：IP 预览（7 步，当天可成）

1. **控制台抄信息**：公网 IP + 确认 root 密码（忘了就重置，重置后需重启实例）
2. **防火墙放行 8080**：轻量服务器 → 实例详情 → 防火墙 → 添加规则（TCP / 8080 / 0.0.0.0/0）。⚠️ 未备案件用 8080，别碰 80/443
3. **网页终端登录**：实例详情 → 远程连接 → Workbench（免装 SSH 工具；粘贴用 Ctrl+Shift+V）
4. **装 Nginx**：
   ```bash
   cat /etc/os-release | head -3          # 先看系统
   # Ubuntu/Debian:
   apt update && apt install -y nginx && systemctl start nginx && systemctl enable nginx
   # Alibaba Cloud Linux/CentOS:
   yum install -y nginx && systemctl start nginx && systemctl enable nginx
   mkdir -p /var/www/website
   ```
5. **本地构建**：`NODE_OPTIONS="" npm run build`（前缀不能省）
6. **上传 dist**：WinSCP（SFTP/22/root，拖拽 dist **里面**的内容到 /var/www/website，别多套一层）或 `scp -r dist/* root@IP:/var/www/website/`
7. **Nginx 配置 + 验收**：
   ```bash
   cat > /etc/nginx/conf.d/website.conf << 'EOF'
   server {
       listen 8080;
       server_name _;
       root /var/www/website;
       index index.html;
       location / { try_files $uri $uri/ $uri.html $uri/index.html =404; }
       location ~* \.(js|css|png|jpg|jpeg|webp|svg|woff2?)$ { expires 30d; add_header Cache-Control "public, immutable"; }
       gzip on; gzip_types text/css application/javascript image/svg+xml; gzip_min_length 1k;
   }
   EOF
   nginx -t && systemctl reload nginx
   ```
   验收：`http://公网IP:8080`（电脑 + 手机移动网络各开一次）

### 排错速查

| 症状 | 排查 |
|---|---|
| 连接超时 | 防火墙 8080 加了吗 / nginx 在跑吗 / 忘加 :8080 / 服务器上 `curl -I http://localhost:8080` 看 200 |
| Nginx 默认欢迎页 | `rm -f /etc/nginx/sites-enabled/default` 后 reload |
| 图片全裂 | 多套了一层目录：`mv /var/www/website/dist/* /var/www/website/` |
| 403 | `chmod -R 755 /var/www/website` |
| scp/WinSCP 拒连 | 22 端口规则 / 密码大小写 / 重置密码后重启实例 |

**后续更新**：重新 build + 上传覆盖即可，无需重启任何服务。

## 阶段 B：正式上线（与 A 并行启动）

1. **买域名**（阿里云同账号）：⚠️ 必须**公司名义**购买并实名（备案主体=域名主体=公司），别用个人学生账号
2. **ICP 备案**（beian.aliyun.com，2~4 周）：主体资料（营业执照/法人身份证）→ 阿里云初审 → 工信部短信核验 → 管局审核。网站名避免"官网/中国"等敏感词
3. **公安备案**：ICP 通过后 30 天内，beian.mps.gov.cn
4. **解析 + HTTPS**：A 记录 @ 和 www → 公网 IP；免费证书（阿里云 SSL 或 certbot）；80 强制跳 443；页脚换真实备案号并链接 beian.miit.gov.cn

## 红线

- IP:8080 仅内部验收，**不对外宣传、不印物料**（长期 IP 提供 Web 服务有管控风险）
- 上线前合规三件套：ICP 备案号、公安备案号、隐私政策
- 学生机带宽通常 1~5Mbps，图片站首屏慢的话后续优化：图片迁 OSS+CDN
