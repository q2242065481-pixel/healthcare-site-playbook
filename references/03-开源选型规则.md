# 03 · 开源选型规则（阶段 2 必读）

> 目标：在 GitHub 找到可直接复用的官网模板，用规则代替感觉。实战结论：ScrewFast / AstroWind 双雄，评分见阶段 2 实例。

## 一、6 条一票否决门槛（全过才进评分）

1. **License 允许商用**：MIT / Apache-2.0 ✓；GPL/SSPL/未见 LICENSE 文件 ✗
2. **响应式**：自带移动端适配（看 demo 站 F12 切手机视图验证）
3. **近 12 个月有维护**：最近 commit 在一年内；issue 无人理的慎选
4. **构建能跑通**：README 有明确 build 命令，依赖正常安装
5. **配置驱动改内容**：文案/图片走配置文件或 content 目录，而不是硬编码散落各处
6. **可静态导出**：能 build 出纯静态文件（不强制依赖 Vercel/Netlify 等境外平台）

## 二、30 分评分表（≥24 直接采用）

| 维度 | 分值 | 看什么 |
|---|---|---|
| 组件覆盖度 | 8 | Hero轮播/大数字/卡片网格/Tab/分栏图文/表单/多列页脚/二级页模板，每有 1 项 +1 |
| 维护活跃度 | 6 | star 趋势、commit 频率、版本更新 |
| 定制成本 | 6 | 主题色是否 CSS 变量/一处可改；多余模块（博客/文档/i18n）好不好剥 |
| 构建友好度 | 5 | 依赖体积、构建速度、报错率 |
| 文档质量 | 5 | README 完整度、demo 站、示例丰富度 |

## 四、行业适配判断（医疗养老）

- 不需要：CMS 后台、i18n 多语言、电商、复杂动效
- 必须补的常见缺口（选谁都大概率要补）：
  - Hero 大图轮播 → 补 Swiper.js
  - 预约/咨询表单后端 → 腾讯问卷/金数据嵌入（国内稳定免后端）或 Formspree
  - 新闻跳公众号 → 模板天然支持外链，零成本

## 五、实战评分实例（2026-09）

| 项目 | 分数 | 结论 |
|---|---|---|
| **ScrewFast** (mearashadowfax/ScrewFast) | 23/30 | 选用底座。组件最齐（含联系表单、数字统计、证言），Preline UI 质感好；代价是要剥 Starlight 文档站和 i18n |

| AstroFlow | 21/30 | 不作底座，仅参考其询价表单页思路 |
