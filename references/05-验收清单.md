# 05 · 验收清单（阶段 4 必读）

> 原则：眼见为实。构建通过 ≠ 页面正常，必须三端截图逐张目检。

## 一、三端截图流程（playwright-core 直驱）

agent-browser 的守护进程模式不稳定（端口残留、假死），验收改用 playwright-core 直驱 Chromium 更可靠：

```javascript
// acceptance_shots.cjs 要点
const { chromium } = require('playwright-core');
// 三档视口：桌面 1440 / 平板 768 / 手机 390
// 遍历所有页面 URL，每个 [页面 × 视口] 全页截图
// 输出命名：site_<页面>_<desktop|tablet|mobile>.png
```

前置：本地 `npx astro preview --port 4321` 起预览服务（同样要带 `NODE_OPTIONS=""`）。

## 二、逐张目检 checklist

每张截图检查：

- [ ] 板块完整，无大片空白或错位
- [ ] 图片全部加载，无裂图（裂图 90% 是路径多套了一层目录）
- [ ] 无横向滚动条（移动端最常见翻车点）
- [ ] 文字不溢出、按钮不挤压（重点看移动端标题和卡片）
- [ ] 导航在手机端折叠为汉堡菜单且可展开
- [ ] 悬浮工具栏不遮挡关键内容
- [ ] 页脚备案条、二维码、链接齐全

## 三、验收交付

- 截图包按 `页面 × 端` 命名归档
- 有问题 → 列问题清单 → 修复 → 复验（直到全过）
- 全过后请用户过目关键截图（首页桌面端、首页移动端、核心二级页），确认后进入部署阶段
